### Engineering Highlights

✔ Enterprise GenAI platform POC
- Multi-agent orchestration with classifier-based routing (LangGraph `StateGraph`)
- Hybrid retrieval architecture (**Milvus + Elasticsearch**, GraphRAG over Neo4j)
- Stateful conversational continuation handling
- ServiceNow ticket automation pipelines
- MongoDB + Redis state management
- S3-based ingestion & retrieval workflows, AWS Bedrock Guardrails for input moderation

✔ Concurrency-safe backend engineering
- Idempotency-ledger patterns for safe operation replay under concurrent requests
- Fail-closed design: ambiguous state is reported, never guessed
- Postgres advisory locking for per-resource mutual exclusion

✔ Backend integrations with **FastAPI & async Python**
- Async API workflows, JWT authentication, REST integrations
- WebSocket-based real-time communication

✔ Retrieval quality engineering
- Exact-match vs. semantic retrieval tradeoffs
- Query normalization strategies & context-grounding improvements
- Chunking & metadata-aware retrieval
